# Sandbox do revisor de regras

Area isolada para preparar arquivos JavaScript e testes de avaliacao do subagente `revisor-de-regras`. Nao faz parte do aplicativo Electron nem altera o sistema Delphi.

- Salve os modulos JavaScript e seus testes em `src/`.
- Execute os testes com `npm test`.
- Mantenha fixtures e dados ficticios nesta pasta; nao copie nem altere o banco real.
